  905: ---    
  906: name: omoc-ercc-diff-verdict    
  907: description: SK06 ERCC Diff + Verdict — expected ⊆ observed 檢查；missing/ambiguous => FAIL_CLOSED；更新 verdict.json/checks_manifest.json    
  908: ---  
  909:   
  910: # SK06 — ERCC 集合比對與 Fail-Closed 裁決（ERCC Diff + Verdict）  
  911:   
  912: ## 1) 目的    
  913: - 把 required contexts 從「宣告」變「可稽核」：集合比對 + 裁決。    
  914: - 規則（Fail-Closed）：    
  915:   - `missing \!= []` → `FAIL_CLOSED`    
  916:   - `ambiguous \!= []` → `FAIL_CLOSED`（同名 checks 歧義風險）    
  917:   - 否則：若 expected 非空且覆蓋 observed → `PASS`  
  918:   
  919: ## 2) 輸入    
  920: - `checks_manifest.json`（SK02/03/04 應已更新）    
  921: - `OMOC_MQ=1` 時，應同時比對 `observed.merge_group`（否則 TT+TEMP_CLOSED）  
  922:   
  923: ## 3) 輸出    
  924: - 更新：`checks_manifest.json.required_contexts_contract.diff/verdict/tt`    
  925: - 更新：`verdict.json.status/tt/reasons`  
  926:   
  927: ## 4) 步驟（One-shot）    
  928: ~~~bash    
  929: set -euo pipefail    
  930: ts="${OMOC_TS:-$(date -u +%Y%m%dT%H%M%SZ)}"    
  931: mq="${OMOC_MQ:-0}"  
  932:   
  933: [ -f checks_manifest.json ] || { echo "missing checks_manifest.json"; exit 2; }    
  934: [ -f verdict.json ] || { echo "missing verdict.json"; exit 2; }  
  935:   
  936: expected="$(jq -c '.required_contexts_contract.expected' checks_manifest.json)"    
  937: obs_pr="$(jq -c '.required_contexts_contract.observed.pull_request' checks_manifest.json)"    
  938: obs_mg="$(jq -c '.required_contexts_contract.observed.merge_group' checks_manifest.json)"  
  939:   
  940: # compute diff for PR    
  941: missing_pr="$(jq -n --argjson e "$expected" --argjson o "$obs_pr" '($e - $o)')"    
  942: extra_pr="$(jq -n --argjson e "$expected" --argjson o "$obs_pr" '($o - $e)')"  
  943:   
  944: # ambiguous: if observed contains duplicate names across sources isn't directly detectable; we enforce uniqueness by scanning expected itself & observed itself    
  945: ambiguous="$(jq -n --argjson e "$expected" --argjson o "$obs_pr" '    
  946:   {    
  947:     expected_dupe: ( ($e|group_by(.)|map(select(length>1))|map(.[0])) ),    
  948:     observed_dupe: ( ($o|group_by(.)|map(select(length>1))|map(.[0])) )    
  949:   } | (.expected_dupe + .observed_dupe) | unique    
  950: ')"  
  951:   
  952: # MQ diff (optional)    
  953: missing_mg='[]'    
  954: extra_mg='[]'    
  955: tt_add='[]'    
  956: if [ "$mq" = "1" ]; then    
  957:   if [ "$(echo "$obs_mg" | jq 'length')" -eq 0 ] && [ "$(echo "$expected" | jq 'length')" -gt 0 ]; then    
  958:     tt_add='["TT-ERCC-MERGE_GROUP-MISSING-001"]'    
  959:   else    
  960:     missing_mg="$(jq -n --argjson e "$expected" --argjson o "$obs_mg" '($e - $o)')"    
  961:     extra_mg="$(jq -n --argjson e "$expected" --argjson o "$obs_mg" '($o - $e)')"    
  962:   fi    
  963: fi  
  964:   
  965: # overall missing/extra: union across required planes    
  966: missing="$(jq -n --argjson a "$missing_pr" --argjson b "$missing_mg" '$a + $b | unique')"    
  967: extra="$(jq -n --argjson a "$extra_pr" --argjson b "$extra_mg" '$a + $b | unique')"  
  968:   
  969: status="PASS"    
  970: reasons='[]'    
  971: tt='[]'  
  972:   
  973: if [ "$(echo "$expected" | jq 'length')" -eq 0 ]; then

  975:   reasons='[{"code":"EXPECTED_EMPTY","message":"No expected required contexts extracted (rulesets/branch protection)."}]'    
  976:   tt='["TT-ERCC-EXPECTED-EMPTY-001"]'    
  977: fi  
  978:

  980:   status="FAIL_CLOSED"    
  981:   reasons="$(jq -n --argjson m "$missing" '[{"code":"MISSING_REQUIRED_CONTEXT","message":"expected contexts missing from observed","missing":$m}]')"    
  982:   tt="$(jq -n --argjson m "$missing" '$m | map("TT-ERCC-MISSING-" + (gsub("[^A-Za-z0-9]+";"_")) )')"    
  983: fi  
  984:   
  985: if [ "$(echo "$ambiguous" | jq 'length')" -gt 0 ]; then    
  986:   status="FAIL_CLOSED"    
  987:   reasons="$(jq -n --argjson a "$ambiguous" '[{"code":"AMBIGUOUS_CONTEXT","message":"duplicate context names detected (risk of exact required contexts ambiguity)","ambiguous":$a}]')"    
  988:   tt="$(jq -n --argjson a "$ambiguous" '$a | map("TT-ERCC-AMBIG-" + (gsub("[^A-Za-z0-9]+";"_")) )')"    
  989: fi  
  990:   
  991: # merge tt additions    
  992: tt="$(jq -n --argjson a "$tt" --argjson b "$tt_add" '$a + $b | unique')"  
  993:   
  994: # update checks_manifest.json    
  995: tmp="$(mktemp)"    
  996: jq --arg ts "$ts" --arg status "$status" --argjson missing "$missing" --argjson extra "$extra" --argjson ambiguous "$ambiguous" --argjson tt "$tt" '    
  997:   .generated_at_utc=$ts    
  998:   | .required_contexts_contract.diff.missing=$missing    
  999:   | .required_contexts_contract.diff.extra=$extra    
  1000:   | .required_contexts_contract.diff.ambiguous=$ambiguous    
  1001:   | .required_contexts_contract.verdict=$status    
  1002:   | .required_contexts_contract.tt=$tt    
  1003: ' checks_manifest.json >"$tmp"    
  1004: mv "$tmp" checks_manifest.json    
  1005: jq -e . checks_manifest.json >/dev/null  
  1006:   
  1007: # update verdict.json    
  1008: tmp="$(mktemp)"    
  1009: jq --arg ts "$ts" --arg status "$status" --argjson reasons "$reasons" --argjson tt "$tt" '    
  1010:   .generated_at_utc=$ts    
  1011:   | .status=$status    
  1012:   | .reasons=$reasons    
  1013:   | .tt=$tt    
  1014:   | .summary=("ERCC verdict="+$status)    
  1015: ' verdict.json >"$tmp"    
  1016: mv "$tmp" verdict.json    
  1017: jq -e . verdict.json >/dev/null  
  1018:   
  1019: echo "SK06 verdict=$status"    
  1020: ~~~  
  1021:   
  1022: ## 5) 驗收點    
  1023: - `jq -e . checks_manifest.json` PASS    
  1024: - `jq -e . verdict.json` PASS    
  1025: - 若 `FAIL_CLOSED`：`verdict.json.tt` 非空  
  1026:   
  1027: ## 6) 最小跡證    
  1028: - root-level `checks_manifest.json`, `verdict.json`    
  1029: - 建議將 `jq .` 輸出存入 `evidence/_acceptance/<ts>/log/`（可用 RB+WI step 模板）
